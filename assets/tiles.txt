# Playfield tiles for ANTIC mode 4 (4 colours). Each tile is 4 pixels wide and 8 rows tall.
#
#   tile <id> <NAME> <map-char> [solid] [oneway] [alt]
#   <8 rows of 4 digits>      0 = background, 1 = COLOR0, 2 = COLOR1, 3 = COLOR2 (COLOR3 for an alt tile)
#
# <NAME> becomes the assembler constant T_<NAME>; <map-char> is what you type in level files
# (write 'none' for tiles that are only ever made by the game, like the flash frame of a fuse).
#
#   solid   blocks movement, bumps heads, and can be stood on (bricks, stairs, belts, ...)
#   oneway  can be stood on from above only; you can jump up through it and walk through it
#   alt     drawn in the second colour (COLOR3) for pixel value 3: the map byte is id + 128, so
#           T_<NAME> is that byte. Use it for a tile that needs a colour the others do not have.
#
#   cap <id> <FAMILY> <L|R|LR> [rows=a-b] [outline=n]
#           the left end, right end, or both ends of a platform tile. You never put these in a map: the
#           asset tool swaps them in wherever the tile's left or right neighbour is something else (the
#           screen edge counts as the same), and the game treats them as the plain tile. Give 8 rows of
#           art, or none and the tool rounds off the plain tile's art itself (rows= limits the rows it
#           changes, outline= is the colour of the new edge).
#
# Ids must be below 128. Ids 16-25 and 32-61 belong to the text font (assets/font.txt); the conveyor
# belts must stay at 64-71 (the game animates those glyphs, and the order is fixed: right slow,
# right, right fast, right accelerating, then the same for left) and their end caps at 72-79 (left
# end), 80-87 (right end) and 88-95 (both), in the same order.
